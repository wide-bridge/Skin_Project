# 05 작업지시서: 정확도개선 및 능동학습 적용판단 (중단)

## 상태
- 본 문서는 `Skin_Proj`의 Qwen3-VL + LoRA 기반 실험 흐름에서 작성되었으나, 현재 단계에서는 **중단** 상태이다.
- 중단은 실패 확정이 아니라, 문제 정의와 프로젝트 우선순위가 바뀌면서 실험 경로를 분리한 것이다.

## 중단 사유
1. `04` 단계까지로 collapse 문제(`all-zero collapse`)는 원인 파악과 1차 제거가 완료되었다.
2. 그러나 그 다음 병목은 단순 LoRA step 증가가 아니라, 데이터 정의와 학습 전략의 불일치에 더 가깝다고 판단되었다.
3. 특히 wrinkle 계열 라벨은 순서형 특성과 경계 불안정성이 강해, 기존 VLM 실험 경로만으로 정확도 개선 여부를 해석하기 어려웠다.
4. 따라서 `Skin_Proj` 안의 VLM 흐름에서 곧바로 능동학습을 붙이기보다, 별도 프로젝트에서 단일 타깃 기준선 검증을 먼저 수행하는 것이 우선이라고 판단하였다.

## 중단 시점에서의 판단
- `Skin_Proj`는 구조 검증과 collapse 제거까지는 의미 있는 진척이 있었다.
- 하지만 정확도 개선과 능동학습 적용판단은, 현재 문맥에서는 직접 이어서 진행하지 않기로 했다.
- 이 주제는 별도 프로젝트에서 데이터 구조와 기준선 성능을 먼저 확인한 뒤 다시 판단하는 것이 더 적절하다.

## 후속 연결
- 후속 실험은 `Skin_wrinkle_proj`에서 진행한다.
- 그 프로젝트에서는 `forehead_wrinkle` 단일 타깃 기준선 검증을 통해 다음 질문을 먼저 확인한다.
  - 데이터가 실제로 학습 가능한가
  - `classification / regression / ordinal` 중 어떤 접근이 더 유효한가
  - `strict split` 기준에서도 일반화 가능성이 있는가
- 이후 결과를 바탕으로, 필요 시 다시 능동학습 적용 가능성을 재검토한다.

## 결론
- `05`는 **중단**이다.
- 중단 사유는 우선순위 부족이 아니라, 문제 정의를 다시 세우기 위해 실험 경로를 분리했기 때문이다.
- 현재 정확도 개선과 능동학습 판단은 `Skin_wrinkle_proj`의 기준선 실험 결과를 본 뒤 재개하는 것이 맞다.
