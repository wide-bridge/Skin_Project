# 02 작업지시서: 주름 실험결과 및 현황정리

## 1. 목적
본 문서는 현재까지 수행한 주름 계열 실험의 결과를 정리하고, 다음 타깃 확장의 기준점을 고정하기 위한 현황 문서이다.

## 2. 공통 조건
- 사용 split: `strict`
- 시나리오 범위: `01`, `02`, `03` 통합
- 주름 계열은 공통적으로 `0~6` 원시 라벨을 `5,6 -> 4`로 remap하여 사용한다.
- 입력 전략은 기본적으로 `pre-crop` 우선 검토를 원칙으로 한다.

## 3. forehead_wrinkle 결과
### 1차 기준선 비교
- `FW-01`: `EfficientNet-B0 + classification`
  - `accuracy = 0.524757`
  - `±1 accuracy = 0.890791`
  - `MAE = 0.604813`
- `FW-02`: `EfficientNet-B0 + regression`
  - `accuracy = 0.551134`
  - `±1 accuracy = 0.954651`
  - `MAE = 0.498843`
- `FW-03`: `EfficientNet-B0 + ordinal`
  - `accuracy = 0.465062`
  - `±1 accuracy = 0.914391`
  - `MAE = 0.637205`
- `FW-04`: `Swin-T + regression`
  - `accuracy = 0.229523`
  - `±1 accuracy = 0.811199`
  - `MAE = 0.959741`

### 재설계 및 backbone 확장
- `FW-05`: `EfficientNet-B0 + regression + pre-crop + staged unfreeze + weak augmentation`
  - `accuracy = 0.596483`
  - `±1 accuracy = 0.967608`
  - `MAE = 0.435909`
- `FW-07`: `EfficientNetV2-S + regression + 256 해상도 + 지연 unfreeze`
  - `accuracy = 0.645997`
  - `±1 accuracy = 0.955576`
  - `MAE = 0.399815`

### 현재 판단
- `forehead_wrinkle`에서는 `regression`이 가장 잘 맞는다.
- `ordinal`은 현재 데이터 조건에서 유리하지 않았다.
- `Swin-T`는 부적합했다.
- 현재 최종 최고 모델은 `FW-07`이다.

## 4. glabellus_wrinkle 결과
- `GW-01`: `EfficientNet-B0 + regression + pre-crop`
  - `accuracy = 0.537714`
  - `±1 accuracy = 0.949098`
  - `MAE = 0.514114`
- `GW-02`: `EfficientNetV2-S + regression + 256 해상도 + 지연 unfreeze`
  - `accuracy = 0.508561`
  - `±1 accuracy = 0.950949`
  - `MAE = 0.551596`

### 현재 판단
- 미간에서는 현재 기준으로 `GW-01`이 더 낫다.
- `V2-S`는 이마에서는 유효했지만, 미간에서는 아직 이득을 만들지 못했다.
- 즉 backbone 확장 효과는 부위별로 다르게 나타났다.

## 5. 현재 기준 결론
- 주름 계열 기본축은 `regression`이다.
- 기본 레시피는 아래와 같이 고정한다.
  - `pre-crop`
  - `strict split`
  - `01/02/03` 통합
  - `weak augmentation`
  - `staged unfreeze`
- backbone 선택은 부위별로 분리 판단한다.
  - `forehead`: `EfficientNetV2-S` 우세
  - `glabellus`: 현재는 `EfficientNet-B0` 우세

## 6. 다음 단계 우선순위
- 다음 주름 타깃은 `l_perocular_wrinkle`, `r_perocular_wrinkle`이다.
- 눈가 주름은 먼저 좌우를 분리한 단일 타깃 baseline으로 시작한다.
- 첫 baseline은 `EfficientNet-B0 + regression + pre-crop`으로 가져간다.

- 현재 재설계 기준은 `04 작업지시서`에서 관리한다.
