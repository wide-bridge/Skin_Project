# 03 작업지시서: crop 데이터 생성 및 저장정책

## 1. 목적
본 문서는 `Skin_wrinkle_proj`에서 사용하는 부위별 crop 데이터의 현재 확보 현황과 운영 원칙을 정리하기 위한 문서이다.

## 2. 저장 위치
- 저장 루트: `D:\vibe_coding\codex\Skin_Project\skin_crop_data`
- 본 폴더는 코드 저장소 안에 두되 Git 추적 대상에서는 제외한다.
- `.gitignore`에서 `skin_crop_data/` 전체를 제외 대상으로 유지한다.

## 3. 현재 확보 현황
현재 확보 또는 재사용 가능한 부위는 아래와 같다.
- `forehead`
- `glabellus`
- `l_perocular`
- `r_perocular`
- `l_cheek`
- `r_cheek`
- `lip`
- `chin`

즉 주름, 색소, 모공, 건조, 처짐 확장에 필요한 핵심 ROI crop은 대부분 준비된 상태로 본다.

## 4. 운영 원칙
- crop 데이터는 원본 이미지를 대체하는 정답 데이터가 아니라, 재사용 가능한 파생 입력 데이터로 본다.
- crop 생성의 직접 목적은 아래와 같다.
  - 반복 학습 속도 향상
  - 입력 일관성 확보
  - 실험 재현성 향상
- pre-crop 입력이 항상 성능을 올린다고 가정하지 않는다.
- 실제 채택 여부는 부위별 baseline과 비교하여 결정한다.

## 5. 현재 판단
- `forehead`에서는 pre-crop 전략이 실제 성능 개선에 기여했다.
- `glabellus`에서도 pre-crop 자체는 유지할 가치가 있다.
- 이후 `perocular` 실험도 같은 crop 기반 입력으로 바로 시작한다.
- `cheek`, `lip`, `chin`은 색소/모공/건조/처짐 확장 시 바로 활용 가능한 상태로 유지한다.
