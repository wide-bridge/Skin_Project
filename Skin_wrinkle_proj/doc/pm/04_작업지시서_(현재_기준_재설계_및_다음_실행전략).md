# 04 작업지시서: 현재 기준 재설계 및 다음 실행전략

## 1. 목적
- 본 문서는 현재까지의 결과를 바탕으로 주름 계열 실험의 재설계 기준을 확정하고, 다음 실행 우선순위를 정리하기 위한 문서이다.

## 2. 확정된 기준
- 공통 기본축은 `regression`이다.
- 공통 입력 전략은 `pre-crop` 우선이다.
- 공통 데이터 범위는 `01/02/03` 통합 + `strict split`이다.
- 공통 학습 전략은 `weak augmentation + staged unfreeze`이다.

## 3. 부위별 backbone 판단
### forehead_wrinkle
- 최종 최고 모델: `FW-07`
- 조합:
  - `EfficientNetV2-S`
  - `regression`
  - `pre-crop`
  - `256 해상도`
  - `지연 unfreeze`
- 현재 판단:
  - 이마에서는 `V2-S` backbone 확장 효과가 실제로 있었다.

### glabellus_wrinkle
- 현재 최고 모델: `GW-01`
- 조합:
  - `EfficientNet-B0`
  - `regression`
  - `pre-crop`
  - `224 해상도`
  - `FW-05식 staged unfreeze`
- 현재 판단:
  - 미간에서는 `V2-S`가 아직 `B0`를 넘지 못했다.
  - 즉 backbone 확대가 모든 부위에 동일하게 유리하다고 가정하지 않는다.

## 4. 학습 스케줄 기준
### B0 계열 기준
- `epoch 1~5`: head only
- `epoch 6~10`: last-stage 일부
- `epoch 11~15`: last-stage 전체
- `epoch 16~20`: middle-stage
- `epoch 21+`: full unfreeze
- `patience = 8`

### V2-S 계열 기준
- `epoch 1~8`: head only
- `epoch 9~16`: last-stage 일부
- `epoch 17~24`: last-stage 전체
- `epoch 25~32`: middle-stage
- `epoch 33+`: full unfreeze
- `max_epochs = 60`
- `patience = 8`
- learning rate는 `0.00015 ~ 0.0002` 범위를 우선 사용한다.

## 5. 현재까지의 설계 결론
- `forehead`는 `V2-S`로 확장할 가치가 확인되었다.
- `glabellus`는 현재 기준으로 `B0`가 더 낫다.
- 따라서 다음 타깃에서는 무조건 큰 backbone부터 쓰지 않는다.
- 먼저 `B0 baseline`으로 부위를 성립시키고, 그 다음에만 `V2-S`를 검토한다.

## 6. 다음 실행 우선순위
### 1순위: 양쪽 눈가 주름
- `l_perocular_wrinkle`
- `r_perocular_wrinkle`

### 실행 원칙
- 좌우를 먼저 분리한 단일 타깃 baseline으로 시작한다.
- 첫 baseline은 아래 조합으로 고정한다.
  - `EfficientNet-B0`
  - `regression`
  - `pre-crop`
  - `strict split`
  - `01/02/03` 통합
  - `weak augmentation`
  - `B0 staged unfreeze`

### 이후 판단
- 좌우 baseline이 성립하면
  - 좌/우 통합
  - 또는 `V2-S`
를 검토한다.

## 7. 이번 단계에서 보류할 것
- `glabellus`에 대한 추가 `V2-M` 실험은 당장 1순위로 두지 않는다.
- `classification -> regression` 또는 `regression -> classification` 연쇄 학습은 현재 우선순위가 아니다.
- `Swin-T` 재실험은 포함하지 않는다.

## 8. 결론
- 현재 기준에서 주름 계열은 `regression + pre-crop + staged unfreeze`를 기본축으로 유지한다.
- backbone 선택은 부위별로 판단한다.
- 다음 단계의 직접 실행 대상은 `perocular wrinkle` baseline이다.
