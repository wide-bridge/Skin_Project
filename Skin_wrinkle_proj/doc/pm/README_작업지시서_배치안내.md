# 작업지시서 배치 안내

현재 `Skin_wrinkle_proj/doc/pm` 문서는 아래 구조로 정리한다.

## 유지 문서
- `00`: GitHub 연결 및 프로젝트 기반설정
- `01`: forehead_wrinkle 단일타깃 기준선 검증 및 초기 실험 범위
- `02`: 주름 실험결과 및 현황정리
- `03`: crop 데이터 생성 및 저장정책
- `04`: 현재 기준 재설계 및 다음 실행전략

## 정리 원칙
- 이미 역할이 끝난 문서는 남겨두기보다 결과 정리 문서와 후속 실행 전략 문서에 흡수한다.
- 비슷한 역할의 문서를 여러 개 유지하지 않는다.
- 결과 문서는 `02`, 운영 정책은 `03`, 다음 실행 기준은 `04`에서 관리한다.

## 제거된 문서
- 기존 `03 작업지시서`는 역할이 흡수되어 삭제하였다.
- 기존 `forehead` 전용 재설계 문서는 현재 기준 재설계 문서로 통합하였다.

## 현재 읽는 순서
1. `00`: 프로젝트 기반 및 저장소 맥락 확인
2. `01`: 최초 실험 목적과 범위 확인
3. `02`: 완료된 주름 실험 결과 확인
4. `03`: crop 데이터 운영정책 확인
5. `04`: 현재 기준 재설계와 다음 실행 우선순위 확인
