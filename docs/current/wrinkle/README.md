# Wrinkle Access Index

이 폴더는 `Skin_wrinkle_proj`의 실행 구조를 대체하지 않습니다.

역할:
- 몇 달 뒤 다시 프로젝트를 볼 때 `wrinkle` 실험축을 빠르게 찾기 위한 상위 접근 인덱스
- 기준 문서, 대표 설정, 대표 스크립트, 대표 산출물, 대표 체크포인트의 진입점 제공

실험축:
- 이마 주름 중증도
- 미간 주름 중증도
- 오른쪽 눈가 주름 중증도
- 왼쪽 눈가 주름 중증도
- 오른쪽 눈가 주름 상태
- 왼쪽 눈가 주름 상태

현재 실제 기준 문서:
- [Skin_wrinkle_proj/doc/pm/current](../../../Skin_wrinkle_proj/doc/pm/current/)

주의:
- 이 폴더는 실행 파일, 데이터, 체크포인트, 산출물을 옮기는 위치가 아닙니다.
- 실제 실행 경로는 계속 `Skin_wrinkle_proj` 아래에 유지합니다.
